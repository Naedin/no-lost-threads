# Notes

A rule states its mechanism and its rung. The incident that produced it goes in the
commit message. Counts and present-tense properties are structure: measured four
times, fires 0 of 5.

```
grep -n 'this session' notes.md   # a fence is not prose
```

A code span is not prose either: `user: ok`. Emergencies and sessions are not
matched; the vocabulary is exact.
